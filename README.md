# Neil's Digital Studio

Personal portfolio for Neil — an AI-accelerated full-stack developer. The site showcases web application work for prospective clients and hiring managers.

## Pages

- **Home** — intro and hero
- **About** — background and experience timeline
- **Projects** — selected web applications with tech details
- **Contact** — inquiry form

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
npm i
npm run dev
```

The app runs at [http://localhost:3000](http://localhost:3000).

```sh
npm run build
npm run preview
```
